# 🎓 The Student Management System

An all-in-one productivity and management application designed to help students organize their academic life, manage daily finances, and stay on top of assignments.

## ✨ Key Features

* **💰 Expense Calculator & Tracker:** Log daily expenses, categorize spending, and calculate total costs to keep student budgets on track.
* **⏱️ Study Time Tracker:** Record and monitor daily study sessions to build consistent habits and track subject-wise focus hours.
* **✅ Smart To-Do List:** Create, prioritize, and check off assignments, deadlines, and daily tasks.
